# Portfolio

Personal portfolio website of Pacôme Ahoussinou. Open `index.html` in a browser, or serve this folder from any static host.

- `index.html`: the standalone site
- `pacome-portfolio.html`: the same page without the HTML shell (source for the published preview)

Edit the `SITE` block near the bottom of `index.html` to change the name, role, email, projects and links.
